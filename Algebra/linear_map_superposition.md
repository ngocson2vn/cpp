# Superposition property of a Linear Map
The superposition property of a linear map means that applying the map to a sum of inputs gives the same result as applying the map to each input separately and then adding those results together. It combines two rules: additivity and homogeneity.

**Key Rules**

- Additivity: Moving two inputs together gives the same output as moving them apart first. If you input $x + y$, the output is $f(x + y) = f(x) + f(y)$.

- Homogeneity: Scaling an input scales the output by the same amount. If you input $cx$, the output is $f(cx) = c f(x)$, where $c$ is a number.

**Combined Property**

- Single Equation: You can write both rules as one step: $f(cx + dy) = c f(x) + d f(y)$.

- Zero Mapping: A linear map always sends zero to zero, meaning $f(0) = 0$.

- Core Test: If an equation breaks either rule, it is not linear.
