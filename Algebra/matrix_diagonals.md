# Matrix Diagonals
Imagine a grid. If you start at any cell and take exactly one step right and one step down, you are moving along a diagonal.

In matrix math, we classify these slanted lines into three categories:

- The **Main Diagonal**: The line starting from the absolute top-left corner and going straight down-right.

- **Superdiagonals**: All the slanted lines above the main diagonal.

- **Subdiagonals**: All the slanted lines below the main diagonal.
