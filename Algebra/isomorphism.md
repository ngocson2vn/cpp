# Isomorphism

An **isomorphism** is an **invertible linear map**.

## Invertibility
An linear map is **invertible** if and only if it is **injective** and **surjective**.

## Injectivity
An linear map $T: V \to W$ is **injective** if and only if it is a one-to-one mapping: <br/>
$`T(u) = T(v) \implies u = v`$.

## Surjectivity
An linear map $T: V \to W$ is **surjective** if and only if its **image** (also called range) equals its **codomain**: <br/>
$`\operatorname{im} T = \big\{ T(v): v \in V \big\} = W`$.
