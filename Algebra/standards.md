# Subset
$S \subseteq I$ <br/>
The symbol $\subseteq$ means that every element in the first set is also in the second set, and the two sets can be equal.

# Set subtraction
$A \setminus B$ <br/>
The symbol $\setminus$ (read as "$A$ minus $B$") refers to a new set containing all elements that belong to set $A$, but do not belong to set $B$.
