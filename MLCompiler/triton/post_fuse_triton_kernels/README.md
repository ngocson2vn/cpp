# Post Fuse Triton Kernels
TorchInductor generates a final Python module that includes all the Triton kernels generated from the original PyTorch model.

It also generates a `call(args)` function to orchestrate the execution of those Triton kernels.

This project aims to inspect the final Python module, identify consecutive fusible pointwise kernels, and fuse them into a single mega Triton kernel.

## model.py
[model.py](./model.py) is the final Python module generated by Inductor.

## compile_model.py
[compile_model.py](./compile_model.py) imports [model.py](./model.py) and compiles Triton kernels into `.cubin` files.
